NOC Syslog Inteligente - Syslog Center

1. Descargar el proyecto.
2. Ejecutar: python -m uvicorn app.main:app --reload
3. Abrir index.html en el navegador.
4. Acceder a http://127.0.0.1:8000/docs para visualizar la API.

Proyecto académico desarrollado para la asignatura Administración y Gestión de Redes.

Funcionalidades
Inventario editable de dispositivos
Gestión de eventos Syslog
Dashboard de monitoreo
Gestión de incidentes
Generador de configuraciones Cisco, Fortinet y Huawei
Consola simulada tipo PuTTY (solo lectura)

Tecnologías
Python
FastAPI
SQLite
SQLAlchemy
HTML
CSS
JavaScript
